# Bilgi Adası

İlkokul çağındaki çocuklar için tek dosyalık, Türkçe bir eğitim oyunu. Soruları çöz, kaynak topla ve kendi adanı kur.

## Nasıl oynanır

`index.html` dosyasını herhangi bir tarayıcıda açman yeterli. Kurulum ya da derleme adımı yok; ilerleme tarayıcıda saklanır.

GitHub Pages açılırsa oyun doğrudan şu adresten oynanabilir:
`https://akincionur-ui.github.io/bilgi-adasi/`
